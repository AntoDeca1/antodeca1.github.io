# Design decisions

Greenfield personal portfolio for hiring teams and researchers. Apple-inspired web aesthetic, implemented in native HTML/CSS rather than an official Apple web component library.

- Design variance: 6. Asymmetric portrait hero, unequal featured projects, publication rows, a full-width calendar, and a split background section.
- Motion intensity: 3. Immediate press feedback and modest hover transitions; native scrolling. No automatic movement or scroll hijacking.
- Visual density: 4. Enough detail to evaluate the work, with expandable project context.
- Native system typography, cool neutrals, a single blue accent, and semantic light/dark tokens.
- Radius scale: 28px panels, 16px diagram nodes, pills for interactive controls.
- Layer scale: 10 sticky navigation, 20 skip link. Glass is reserved for navigation.
- On mobile, each multi-column section collapses explicitly. The calendar retains horizontal scrolling and initially shows recent activity.
- Semantic links, visible focus, keyboard day navigation, reduced motion, reduced transparency, and increased contrast preferences.
- All projects, papers, and credentials are based on verified public sources. No invented performance metrics, testimonials, availability claims, or private activity details.

References: [Apple design](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md), [GitHub Pages custom workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
